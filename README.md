# 📌 Project Overview

This project analyses the AI open-source ecosystem by exploring repository popularity, community engagement, technology adoption, repository health, and growth trends.

The dashboard is designed for executive decision-making through interactive visualisations, KPI cards, custom Deneb charts, and dynamic filtering.

# 💡 Key Insights

The analysis identified several important trends across the AI open-source ecosystem:

- Python remains the dominant programming language.
- Large Language Models and Generative AI repositories demonstrate the highest community engagement.
- Repository health generally improves as repositories mature.
- Community engagement strongly influences repository popularity.
- Modern AI frameworks such as PyTorch and TensorFlow continue to dominate repository development.
- Repository growth has accelerated significantly in recent years.

# 🚀 How to Use

1. Download the **Power BI (.pbix)** file from the **Power BI Dashboard** folder.
2. Open the file using **Microsoft Power BI Desktop**.
3. Explore the four interactive dashboard pages.
4. Use the slicers to filter by:
   - Category
   - Organisation
5. Navigate between pages using the sidebar buttons.
6. Hover over visuals to view additional insights and tooltips.
